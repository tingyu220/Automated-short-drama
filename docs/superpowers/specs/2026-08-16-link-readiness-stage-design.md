# 链接就绪阶段设计

## 1. 目标与范围

将“剧目上线后提取番茄链接，并在投放系统搭建可直接上剧的推广内容”做成独立、可恢复的阶段流水线。

本期终点固定为“推广内容已就绪”，不执行账户分配、素材处理、计划生成、计划提交、状态轮询或飞书 M 列完成回写。

番茄链接只能在剧目上线时间到达后提取；未到时间不得访问番茄或占用投放系统资源。

## 2. 阶段模型

本期定义以下连续阶段：

1. `WAITING_AVAILABLE_TIME`：等待剧目上线时间。
2. `LINK_EXTRACTION`：从番茄获取 IAA、2.9、9.9 链接，成功后冻结并回填飞书 J/K/L。
3. `DELIVERY_DRAMA`：在投放系统按剧名查找剧目资源，命中则复用，不存在才创建。
4. `PROMOTION_CONFIG`：为每条有效链接创建或复用对应推广内容。
5. `LINK_READY`：链接、剧目资源和推广内容均已确认，作为本期终态。

任务可指定运行终点。本期只开放至 `LINK_READY`；后续扩展账户、素材、计划草稿、提交和完成轮询时，以新增阶段继续向后串接，不改写本期阶段的含义。

## 3. 番茄链接获取

进入 `LINK_EXTRACTION` 前，按现有“标准化剧名 + 上海时区分钟”的列表与详情二次校验定位剧目。

对于每种链接，系统必须先进入番茄“推广链接”列表：

- IAA：以剧名与规则选集（集数大于 50 选第 2 集，否则选第 1 集）定位；
- IAP：以剧名与已匹配的模板定位，模板继续采用已发布的 2.9/9.9 价格规则；
- 若命中既有链接，点击“查看”并提取链接，不点击创建；
- 未命中时才创建该链接，并立即读取创建结果；
- 多条、无法明确匹配、查看结果为空或剧名不一致，全部转 `MANUAL_REVIEW`。

IAA 是进入投放系统搭建的最低链接条件：IAA 成功并验证后，即使 IAP 模板扫描或某个 IAP 档位创建失败，也继续使用所有已成功链接搭建剧目与推广内容。IAP 失败必须在 `LINK_EXTRACTION` StepRun 中记录档位、错误码和原因；IAA 自身失败才阻断后续阶段。

链接去重键保持 `task_id + link_type + url_hash`。已验证冻结的任务不再次访问番茄。

## 4. 投放系统搭建

链接提取成功后，对整个剧目先执行一次 `DELIVERY_DRAMA`：

- 按漫剧名称搜索投放系统剧目；
- 搜到可用剧目 ID 时复用；
- 未找到时使用一条已验证链接创建剧目，并回读剧目 ID；
- 创建结果不明确时标记 `RESULT_UNCERTAIN`，先搜索核对，禁止直接重复创建。

随后按 IAA、2.9、9.9 的有效链接执行 `PROMOTION_CONFIG`：

- 按约定名称搜索已有推广内容；
- 已存在时复用；
- 不存在时填写主剧、分销商“微智造”和该条链接后创建；
- 保存后必须验证主剧与链接匹配；不匹配、结果不明确时停止并人工处理。

只有所有有效链接都已具备对应推广内容，任务才能进入 `LINK_READY`。

## 5. 恢复、审计与边界

- 每个阶段独立持久化状态、输入快照、输出标识、执行时间、错误码与截图。
- 重试从未完成或失败阶段开始；前面已确认成功的阶段直接复用输出，不重复创建链接、剧目或推广内容。
- 人工处理后可从指定阶段重试；任务停止在 `MANUAL_REVIEW`，不自动进入后续阶段。
- 单 Worker、单浏览器、单标签页串行处理，避免串号与重复操作。
- `LINK_READY` 不分配账户，不构建、填写或提交投放计划；不写飞书 M=1。

## 6. 页面与交互

任务详情展示阶段进度、每阶段的输入和产物：番茄链接、投放剧目 ID、推广内容名称及最后错误。

用户操作仅提供：

- 运行到“提取链接”；
- 运行到“链接已就绪”；
- 从失败阶段重试；
- 暂停。

未到上线时间的“运行”操作显示等待原因，不触发外部平台调用。

## 7. 验收标准

- 任务在上线时间前不会操作番茄或投放系统。
- 已创建的番茄链接通过搜索与查看复用，不重复创建。
- 新链接只创建一次，随后能冻结并回填飞书。
- 投放系统总是先复用或创建剧目，再复用或创建各链接的推广内容。
- 任一阶段失败后可从该阶段恢复，已成功阶段不重复执行。
- 本期运行至 `LINK_READY` 时，不产生账户分配、素材选择、计划提交和 M=1 写入。
