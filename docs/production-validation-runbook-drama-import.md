# 当日剧目导入验证 Runbook

## 前置

- 公用表、私有表 URL 与 Sheet ID 已配置；公用表只读。
- 本机 `lark-cli` 已完成 user 身份授权；Windows 通过 Node CLI 脚本调用，URL 的 `&sheet=` 参数不会被批处理解析。
- 后端和 Dashboard 已启动，自动扫描 Worker 在验证阶段保持关闭。

## 操作步骤

1. 打开“自动搭链接”，点击“读取今日剧目”。
2. 核对业务日为北京时间；预览中的剧目顺序和 E 列时间必须与公用表完全一致。
3. 核对新增、重复、异常数量；带 `N=OK` 且已有 J/K/L 的剧目显示为“可复用”。
4. 仅在确认新增行、重复判断和异常均符合预期后，点击“确认导入”。
5. 系统应把新增剧目插入私有表第 2 行，并回读 A:N 验证；旧剧目下移。
6. 刷新任务列表，确认后续任务仅由私有表生成；到点前不得访问番茄或投放系统。

## 异常处理

- 预览显示表格版本变化：重新读取预览，不得继续确认旧预览。
- 回读不一致、同名同时间歧义或飞书写入失败：停止确认，保留本地导入记录并人工核对。
- 重复点击确认：必须返回同一运行结果，不能二次插入。
