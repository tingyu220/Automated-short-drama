# 短剧投放全流程自动化工作台 V1 业务规则

版本：V1
适用范围：飞书剧目读取、链接提取回填、账户分配、素材分组、标准投放计划生成与完成回写。
冲突处理：本规则与设计文档冲突时，以已合并补充规范的设计文档为准。

## 1. 链接规则

### 1.1 IAA 选集边界

- IAA 链接只能从番茄免费入口提取，本地禁止构造或拼接链接。
- 选集阈值默认 50：选集数 `> 50` 选第 2 集，`<= 50` 选第 1 集。
- 链接长度不等于 501 记为 `SPECIAL_LENGTH`，不判为无效。

### 1.2 IAP 模板区间与排序

- IAP 2.9：目标价格 2.9，区间 `2.6 - 5.0`。
- IAP 9.9：目标价格 9.9，区间 `8.8 - 13.8`。
- 扫描全部可见模板，按“档位1价格”分类；区间外的模板忽略。
- 排序规则：同距离优先高价；距离相同时按价格高、页面靠前排序。
- 无匹配 IAP 模板属正常业务结果，不导致整剧失败。

### 1.3 剧变来源字段

- 剧变不进入番茄提取，直接读取飞书剧目表已有 J/K/L 链接。
- 剧变来源标识：`JUBIAN / FEISHU_SHEET / DIRECT_READ / J|K|L`。
- 剧变读到的空值表示该类型链接不存在，不构造链接。

### 1.4 链接状态

链接状态流转值：`NOT_STARTED / EXTRACTING / AVAILABLE / NOT_AVAILABLE / SPECIAL_LENGTH / VALIDATED / DRAMA_MISMATCH / FAILED`。

- 链接与主剧不匹配：停止处理、截图、进入 `MANUAL_REVIEW`；禁止自动更换主剧或剧名。
- 链接提取成功并回填飞书 J/K/L 后，按下方完成规则写 M。

### 1.5 来源可追踪

每条链接统一记录：`task_id、drama_name、link_type、promotion_url、source_platform、source_entry、acquisition_method、source_column、url_length、link_status、acquired_at、rule_version`。

- 番茄来源：`TOMATO / FREE|PAID / PAGE_EXTRACTION`。
- 剧变来源：`JUBIAN / FEISHU_SHEET / DIRECT_READ / J|K|L`。
- 链接去重键：`task_id + link_type + url_hash`。
- 任意有效链接（IAA/2.9/9.9）都可获取专辑 ID，默认顺序 IAA → 2.9 → 9.9。

## 2. 账户与素材规则

### 2.1 账户块结构

- IAA 账户块结构：`3+3+3+1`，即 `B1×3 + B4×3 + B7×3 + BX×1`，同一剧名下连续 10 行为一个完整块，整块一起上一部剧。
- IAP 账户块结构：`3+3`，即 `B1-9.9×3 + B2-2.9×3`，6 行为一个完整块。
- 块结构 V1 写死；不写死物理行号、账户名称、CID。

### 2.2 空位扫描

- 分配前必须重新读取飞书账户表最新数据，从表头向下找第一个完整可用块。
- 完整可用块条件：块内剧名全部为空、全部启用、结构完整、同一 CID 当天未分配。
- 只有部分行空白不算可用块；只写空剧名，绝不覆盖已有剧名。
- 回填后回读确认；部分写入标记 `PARTIAL_WRITE` 并进入人工处理。

IAP 分配组合：

- 只有 9.9：找完整 B1-9.9 三行组并回填。
- 只有 2.9：找完整 B2-2.9 三行组并回填。
- 同时有 9.9 和 2.9：必须同时找到两组（6 行）一起回填；只找到一组不做部分分配，进入 `MANUAL_REVIEW`。
- 无匹配模板：不分配 IAP 账户，属正常业务结果。

### 2.3 追加块

- 老块不覆盖；无可用空位时，在表尾追加标准块。
- 追加块从最近一个完整启用块复制：账户名称、CID、账户组、启用状态；不复制剧名、是否测试户、备注。

### 2.4 测试户挑选

- 默认从当前剧已分配的 IAA-B4 三行中挑选一个：启用、未标记、本批次未被其他测试任务使用，然后写“是”。
- 同一批次测试户唯一。
- 测试户来源后续可配置：`测试户账户表 / IAA-B4 / 自动`；V1 默认 `IAA-B4 自动挑选`。

### 2.5 素材通铺

- 操作顺序：清空原有素材 → 搜索精确剧名 → 每页 300 条 → 全选当前页 → 完成。
- 校验：已选素材数必须等于剧目有效素材总数，不一致时停止提交。

### 2.6 素材分组公式

常规素材分组（N 为有效素材总数）：

- `N <= 30`：1 组复制 2 次，共 3 组。
- `30 < N <= 60`：每组 `ceil(N/2)`，2 组各复制 2 次，共 6 组。
- `60 < N <= 90`：每组 `ceil(N/3)`，3 组各复制 1 次，共 6 组。
- `N > 90`：均匀分配，每组 `<= 30`，组数取不小于 `ceil(N/30)` 的最小 3 的倍数。
- 常规计划：`ad_limit_per_project = 最终组数 / 3`，`expected_project_count = 3`。

测试户素材分组（T 为测试素材条数，G_test 为测试素材组数）：

- `T < 20`：每组 2 条；`T >= 20`：每组 3 条；不复制。
- `ad_limit = min(10, ceil(G_test/3))`，`project_count = ceil(G_test / ad_limit)`。

## 3. 计划与完成规则

### 3.1 标准计划固定字段

- 创编方式：极速创建；投放方式：标准投放；推广业务：端原生。
- 项目规则：按广告数生成；广告规则：按素材组生成。
- 素材组平均分配：关闭；标题组平均分配：关闭。
- 固定字段：主剧 = 当前剧目；分销商 = 微智造；推广链接 = 对应类型链接。
- 推广内容配置只创建缺失项，命名：`iaa-平台-剧名` / `9.9-平台-剧名` / `2.9-平台-剧名`。

### 3.2 命名模板

原样复制使用：

- 端付：`<平台方>#端付<剧名称><日期>ubr-<创建日期>-<时分秒-n>`
- 端免：`<平台方>#端免<剧名称><日期>bxr-<创建日期>-<时分秒-n>`
- 测试：`<平台方>#测试<剧名称><日期>cbo-<创建日期>-<时分秒-n>`
- 漫剧全域：`<平台方>#漫剧全域<剧名称><日期>bxr-<创建日期>-<时分秒-n>`（V1 预留）

### 3.3 CID 配置

- 配置字段：CID、广告预设、抖音号、开户预设、主体、投放类型、生效时间、启用状态。
- V1 仅建立配置结构；具体值由用户在真实提交前通过 Dashboard 录入。
- 同一 CID 当天不分配第二部剧；PlanSpec 保存账户快照。

### 3.4 PlanSpec 校验

- 校验内容：CID 映射、模板匹配、命名规则。
- 默认 `ALLOW_FINAL_SUBMIT=false`；仅开启后允许真实提交标准投放计划。
- `RESULT_UNCERTAIN`：创建操作超时或结果不明确时，先查询外部平台；找到目标资源则补记成功，确认不存在才允许重试；禁止直接重复点击创建或提交。

### 3.5 巨量V2 状态为最终完成来源

- 任务完成状态以投放系统巨量引擎 V2 任务页为最终来源。
- 轮询：每 5 分钟一次，最长 2 小时；失败重试上限 3 次。
- 状态 = 已完成：写飞书 M=1，N 自动变 OK；清理活动队列项，保留台账与日志。
- 失败、部分失败或超时：进入 `MANUAL_REVIEW`，本地记录原因与截图。
- M=1 仅在“真实提交且巨量V2 状态=已完成”后写入；Dry Run 不写飞书表、不写 M。

## 4. 验证与维护

- 本规则覆盖链接、账户、素材、计划与完成五类核心规则；规则值变更通过规则与配置中心发布新版。
- 运行中任务继续使用其配置快照；新任务读取已发布规则版本。
