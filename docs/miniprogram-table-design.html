小程序剧目表结构设计（Sheet: 2NgJYM）

根据用户描述的完整小程序投放流程设计，一行 = 一部剧 + 一个价格档位。

设计原则：
  • 一部剧两个档位（2.9 / 9.9）= 两行数据
  • 固定配置（小程序信息、主体、渠道等）在每行重复，便于筛选和独立操作
  • 从剧目表（a8d032）读取基础信息后补充小程序专属字段
